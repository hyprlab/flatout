Cloudflare Turnstile

Adds a Cloudflare challenge to the sign-in and sign-up pages, which stops most automated password guessing and sign-up spam. It needs a free widget from the Cloudflare dashboard with this site's hostname in its list.

{{ 'On' if turnstile.on else 'Off' }} {%- if turnstile.source == 'environment' %}From the TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY environment variables. Keys saved here take over from them. {%- elif turnstile.on %}Sign-in and sign-up show a challenge. {%- else %}Sign-in and sign-up have no challenge.{% endif -%}

Complete the challenge. It proves the keys belong together and work on this address before anyone is asked to pass it.

Locked out of sign-in anyway? On the server, docker exec {{ app_package }} flask turnstile off turns it off.

Back up everything

One file with the accounts, the site and its media, the repository with every build, and the signing key, encrypted with a passphrase you choose. To move to a new server, or recover, start a fresh install and choose Restore from a backup in its setup.

Download

Make a backup

At least 12 characters. Keep it somewhere safe: without it nobody can open the backup, you included. The server forgets it once the backup is made.

A large backup restores more easily from the server: copy it into the volume, then on the fresh install run docker exec -it {{ app_package }} flask restore-backup /data/<file>.
