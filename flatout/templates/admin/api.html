For AI agents: the MCP server

Agents that speak the Model Context Protocol can edit the site and publish releases through tools, with a token in the Authorization header.

Server address
{{ base_url }}/mcp

Claude Code

claude mcp add --transport http flatout {{ base_url }}/mcp --header "Authorization: Bearer YOUR_TOKEN"

Clients configured with JSON

{
  "mcpServers": {
    "flatout": {
      "type": "http",
      "url": "{{ base_url }}/mcp",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

Every endpoint, with its parameters

Publish a release from CI

curl -fsS -H "Authorization: Bearer $FLATOUT_TOKEN" \
  -F file=@app-x86_64.flatpak -F channel=stable -F notes="$(cat NOTES.md)" \
  {{ base_url }}/api/v1/releases

Promote the beta to stable

curl -fsS -H "Authorization: Bearer $FLATOUT_TOKEN" -H "Content-Type: application/json" \
  -d '{"from": "beta", "to": "stable"}' {{ base_url }}/api/v1/releases/promote

Change the headline and publish

curl -fsS -X PATCH -H "Authorization: Bearer $FLATOUT_TOKEN" -H "Content-Type: application/json" \
  -d '{"title": "A new headline"}' {{ base_url }}/api/v1/site/sections/top
curl -fsS -X POST -H "Authorization: Bearer $FLATOUT_TOKEN" {{ base_url }}/api/v1/site/publish
